# QuickNotes

A minimal Android app for quickly creating, editing, and deleting local text notes.

## Features
- Create a new note (title + text)
- View a list of all saved notes
- Edit an existing note
- Delete a note
- Empty-state message when no notes exist
- Notes persist locally between app sessions
